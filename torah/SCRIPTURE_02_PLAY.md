# Scripture 2, Play

You can run one song or one saved session at a time. To start a specific song, say “start bingo test”, “start baby brobots”, or “start fart joke”.

You can also play any song (or just part of it) with “system-play” followed by the song name. Optional details include the starting step, ending step, which robot should perform it (1 or 2), and whether to do a dry run.

Available steps are listed under “system-score”. To replay a previously saved session, say “replay” then the session name. To stop whatever is currently playing, say “stop run.” If you want to change any of this, go to Scripture 3.

## Commandments

- start bingo test, the Bingo test
- start baby brobots, the Baby Brobots nap song
- start fart joke, the Fart Joke
- system-play, a song or part of it: <song> [from <step>] [to <step>] [robot 1|2] [dry] (steps: system-score)
- replay, a saved session - add its name
- stop run, stops the song playing

*Something to change? Go to scripture 3.*

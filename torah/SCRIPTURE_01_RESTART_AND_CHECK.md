# Scripture 1, Restart and check

Just started, or made some edits? This is where every show begins. Say “system-restart” for a fresh start, just like wpr 2: the speaker and mic get set, and the page reloads itself. While the reporters warm up, “system-skip”, or the Esc key, skips their lines.

Then make sure everything is up. “system-status” shows Wire-Pod, the language model, the page, any run and the batteries. “system-check” makes sure every file is where it should be, and “system-test-all” runs the full audit, PASS or FAIL for each part.

All PASS? Go to Scripture 2 to play, or Scripture 3 to edit.

## Commandments

- system-restart, a forced restart, like wpr 2 - speaker and mic set; the page reloads itself (Enter to confirm)
- system-skip, skip the voiced lines playing - in the tour, on to the next scripture (Esc exits the run)
- system-status, Wire-Pod, language model, page, run, battery
- system-test-all, the full audit, PASS / FAIL for each
- system-check, every file named is there; story.md / knobs match

*All PASS? Go to scripture 2 to play, or 3 to edit.*

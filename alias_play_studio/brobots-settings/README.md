# Brobots settings
- **words:** gofps, gopower, frame rate, 30 fps, 60 fps, performance profile, balanced, normal, high, brobots hot, brobots hyper
- **ask:** What are the Brobots settings aliases?
- **about:** the terminal's 1.6-rebuild switches for the Brobots (~/.gopod_alias_lib/brobots.sh), set over the network - both Brobots, or one (1|2)
---

## Tour
1. Set once for the show: “gofps 30” - cooler, calmer, easier on the battery; reboot the Brobots for it.
2. Then “gopower balanced” - the show's profile; no reboot.
3. Not sure what they're on? “gofps” and “gopower” alone say.

## Commandments
1. gofps, the face's frame rate: 30|60 [1|2] - after the Brobot reboots; alone: what each is set to
2. gopower, the performance profile: normal (533 MHz, the least battery) | balanced (729 MHz) | high (1.26 GHz, hotter) [1|2] - at once; alone: what each is on

# SDK

The robot SDKs GOPOD builds on. They're big and they're other people's code, so they aren't in
this repo: clone each one into `~/crushn8r_git/SDK/sources/<name>/`, where GOPOD looks for them.

| Name | What GOPOD uses it for | From |
|---|---|---|
| `vector-go-sdk` | Wire-Pod's Go link to the Vector robots | [fforchino/vector-go-sdk](https://github.com/fforchino/vector-go-sdk) |
| `wirepod-vector-python-sdk` | The Python tools that talk to the robots | [kercre123/wirepod-vector-python-sdk](https://github.com/kercre123/wirepod-vector-python-sdk) |
| `vectorx` | The live Bingo game (`gobingo`) and its sound files (`vectorfs/`) | [fforchino/vectorx](https://github.com/fforchino/vectorx) |
| `Viccyware` | Vector's own animation and trigger names | [The-Viccyware-Group/Viccyware](https://github.com/The-Viccyware-Group/Viccyware) |
| `cozmo-python-sdk` | Cozmo, the next robot pair (not wired yet) | [anki/cozmo-python-sdk](https://github.com/anki/cozmo-python-sdk) |
| `Scout-open-source` | Moorebot Scout, the next robot pair (not wired yet) | [Pilot-Labs-Dev/Scout-open-source](https://github.com/Pilot-Labs-Dev/Scout-open-source) |

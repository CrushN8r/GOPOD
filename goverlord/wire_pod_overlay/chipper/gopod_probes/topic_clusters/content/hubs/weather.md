## The weather chain
1. Goverlord hands the weather to KEYS - KEYS holds the weather API key.
2. KEYS hands it to PLAYHEAD - the weather API, with the location and the time.
3. Getting the weather details is intern GIT REPO's assignment, from PLAYHEAD - watching the USB ports is his assignment too.
4. GIT REPO hands the weather details to intern CACHE PYC, to display.
5. CACHE PYC's assignment is to display the weather details - the details stay GIT REPO's responsibility.

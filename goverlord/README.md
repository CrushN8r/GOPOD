# goverlord

GOPOD's working parts - everything that runs the show.

| Folder | What's in it |
|---|---|
| [`wire_pod_overlay/`](wire_pod_overlay/) | What GOPOD adds to Wire-Pod: the code, the chat page, the settings, and the cards every persona looks things up in. |
| [`runtime/`](runtime/) | What plays: the songs, the room mic, the voices, the models. |
| [`alias_lib_overlay/`](alias_lib_overlay/) | The terminal aliases. Each one's card: [alias_play_studio/](../alias_play_studio/). |
| [`SDK/`](SDK/) | The robot SDKs GOPOD builds on, and where to get them. |
| `gopod_paths.sh` | Changes this machine's paths to yours, in one go. |

New here? [GOPOD_YOURSELF.md](../GOPOD_YOURSELF.md) walks the whole way.

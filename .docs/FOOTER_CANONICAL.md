addition of `MY_NICHE_BUZZ_ASK.md`, all 2026-08-18). This file's own row count below is the
current truth; recount rather than trust a cited number the next time a doc is added or
removed. Heading renamed from `## More` to `## GOPOD YAHMM (You Are Here Mall Map)`
2026-08-17, matching README.md's own top-of-page mall map. Restructured the same day from
a flat grouped list into a two-door flow — Door 1 (wide: plain-language, first-look) and
Door 2 (deep: technical, operator tooling, philosophy) — every door preserved, re-sorted
not culled.

**Each doc's own copy of this footer omits that doc's own line.** A doc never links to
itself. README.md's copy therefore omits its own "Start here" line — every other
"Start here" doc still appears. A group with no members left after self-omission (e.g.
`AI_AHA_MOMENTS.md`'s own copy of "How this gets made") is dropped entirely, not shown
empty.

Paths below are repo-root-relative (this file's own location, `.docs/FOOTER_CANONICAL.md`,
is one level down — these are NOT relative to `.docs/`). Propagating this block into a doc
that lives at a different depth (e.g. `tech/alias_play_studio/`, one level down; or `life/`,
also one level down) means adjusting each path for that doc's own relative position —
mechanical, not done in this task.

Grouped into two doors, wide then deep, each door itself grouped by reader lane — the
survey's §6 reader-lane read is still the starting map for which lane a doc sits in; which
door it sits in follows the wide/deep judgment in
`gopod_notes/YAHMM_TWO_DOOR_RESTRUCTURE_001.md`.

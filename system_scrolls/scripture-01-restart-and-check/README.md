# Scripture 1, Restart and check
- **words:** scripture 1, restart and check, system-restart, system-skip, system-status, system-test-all, system-check
- **ask:** What's in Scripture 1, Restart and check?
- **about:** written by GOPOD from the system window (system-menu.md) - system-scrolls writes it again; system-tour reads it from here

## Tour
1. Just started, or made some edits? This is where every show begins. Say “system-restart” for a fresh start, just like wpr 2: the speaker and mic get set, and the page reloads itself. While the reporters warm up, “system-skip”, or the Esc key, skips their lines.
2. Then make sure everything is up. “system-status” shows Wire-Pod, the language model, the page, any run and the batteries. “system-check” makes sure every file is where it should be, and “system-test-all” runs the full audit, PASS or FAIL for each part.
3. All PASS? Go to Scripture 2 to play, or Scripture 3 to edit.

## Commandments
1. system-restart, a forced restart, like wpr 2 - speaker and mic set; the page reloads itself (Enter to confirm)
2. system-skip, skip the voiced lines playing - in the tour, on to the next scripture (Esc exits the run)
3. system-status, Wire-Pod, language model, page, run, battery
4. system-test-all, the full audit, PASS / FAIL for each
5. system-check, every file named is there; story.md / knobs match

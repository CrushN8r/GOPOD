## Tour
1. Turn parts on or off for this session. “system-numpad” shows who each numpad key talks to; “on” makes the keys push-to-talk, “off” lets them type as usual. “system-gap” sets the reporter gap for system-play.
2. “system-tweaks on” plays the moves with their tuned values, “system-native” turns Wire-Pod's own voice answers on or off, and “system-record” turns Record Session on or off. When you're done, close the window with the speaker icon.

## Commandments
1. system-numpad, each numpad key: who it talks to, live or not
2. system-numpad on, numpad keys are push-to-talk
3. system-numpad off, numpad keys type as usual
4. system-gap, reporter gap for system-play: <seconds> | off | default
5. system-tweaks on, apply phcal tweaks before a live system-play
6. system-tweaks off, play the moves as written
7. system-native on, Wire-Pod's own voice answers on
8. system-native off, Wire-Pod's own voice answers off
9. system-record on, Record Session on (the page's Record? box)
10. system-record off, Record Session off, kept zipped
11. system-robots-off on, Robots off: the Brobots' says on the page in their numpad voices, says and animations captured
12. system-robots-off off, Robots back on
13. system-run-check off, sound off for a run check: robots off and the page muted, the chat drawn as ever; start any run
14. system-run-check on, sound back on; the run check's chat lines saved
15. system-run-check replay, plays the saved run check again on the page, at normal volume

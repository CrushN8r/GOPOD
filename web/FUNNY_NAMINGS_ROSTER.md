# Funny Namings Roster

**What this is.** A distilled, tagged index of GOPOD's invented vocabulary — names,
acronyms, phrases, metaphors — pulled from the operator's raw AI-sweep source
("Super_funny_namings"). This is STEP 1 only: a companion roster/index, built to feed a
future word-search tool and other content use. It is **not** the word-search tool itself
(that's separate, later work, not touched here), and it is **not** a competing glossary
to [`FUNNY_NAMINGS.md`](FUNNY_NAMINGS.md) — that file is the living, explained-once glossary
("every name, character and phrase this project uses, explained once"); this roster is a
compact, exhaustive, tagged list built for lookup/query use, drawing from a much larger raw
source than the curated glossary covers. Where a term also appears in `FUNNY_NAMINGS.md`,
that file is the explanation; this file is the index entry.

**Tags used on every entry:**
- `[1W]` = single word, word-search-grid-ready as-is. `[MW]` = multi-word phrase (fine for
  glossary/content use; would need splitting/compounding for an actual word-search grid).
- `[cur]` = current/live GOPOD vocabulary. `[hist]` = the raw source's own author flagged
  this as historical/source-food/older, not current canon (kept, not dropped — a public
  word-search built from stale vs. live terminology is the operator's own future call).

Grouping follows the raw source's own section structure. Source: `Super_funny_namings`
raw sweep, pasted verbatim by the operator (path on disk at build time:
`/home/goverlord/.claude/jobs/aa0d4559/tmp/super_funny_namings_raw.md` — a temp job path,
not a repo path; the content is fully absorbed into this roster).

## GOPOD Yourself — the one name to remember

Say "Hey Vector, GOPOD Yourself" out loud and the whole thing starts — it's the wake phrase that switches a Vector robot from idle to on. It isn't just a way to start a robot. It's an invitation: your turn.

for real today. Not one of the four above for that reason, but not gone either.

## The words this project uses

- **WAWN** — "Where Are We Now?" — the question asked to get reoriented.
- **WWAN** — "Where We Are Now" — the plain statement that answers it.
- **Bait** — the short video made to catch a stranger's attention.
- **The net** — the same video, once it's posted publicly to catch that attention wide.
- **Dinner before dessert** — finish and prove the thing that's real before building the next exciting thing on top of it.
- **Golden** — tested and proven to work; the trusted version to build on.
- **Controlled Explosion** — growth or a release let out in staged, bounded, proof-bearing steps, each one reviewed before the next goes live — never everything dumped out unproven at once. The opposite of "fire a sequence and hope."
- **Banked** — finished and locked in. Done for good, not still in progress.
- **Coming soon** — named and planned, not built yet, said plainly instead of left unsaid.
- **Backpack lane** — the fallback way a brobot answers when nothing scripted fits; a general conversation.
- **Doc's Take** — the short write-up Doc gives when a real mistake becomes a lasting rule.
- **Vampired** — a song-video that carries the vamp, the detachable pre-show module that
  fills a live generation-wait (Brobot 3/4 vamping through fallback beats while the content
  writes itself backstage). "The vampired interview" is the catchy title for the
  interview-with-vamp video — see `SONG_SCAFFOLD.md`'s "The vamp — a detachable pre-show
  module" section for the full model.
- **YAHMM** — "You Are Here Mall Map" — the navigation every doc in this repo ends with.
  Two doors, wide and deep, so a reader always knows where they are and where else they
  could go — nothing here ever dead-ends.

### Golden, proof, and guts

- **Golden guts** — the real, proven configuration behind a feature, not a sketch of one.
- **Last-known-good** — the most recent config confirmed working — the fallback when something breaks.
- **PASS / BLOCKED** — the two-word verdict every dry-run or live test ends on. No in-between.
- **Field proof** — confirmed by an actual run in front of real hardware, not just reasoned out on paper.
- **Not proven / proven live** — the line between "should work" and "has actually worked, watched."
- **Frame 0** — the pre-flight moment before a robot does anything: connect, check, prove it's ready.

### Digestion — how raw material becomes real work

- **Source-food** — raw, unprocessed material (a pasted transcript, an old note) waiting to become something real.
- **Digest** — turn that raw material into structure and behavior that actually live in the repo.
- **Poop / wipe / waste** — what's left once the useful part's been digested out — discarded on purpose.
- **Compost / prune** — cutting dead material back so what's still alive can grow better.
- **Seed / grow / fruit / harvest** — the other half of the same metaphor: something small planted, tended, and eventually proven. "Proof is fruit."

### Robot timing and control

- **Piston pulse** — the timing/calibration rhythm a robot's own movements run on.
- **Latency hiding** — covering a wait (an LLM generating a line, say) with a movement, so it never reads as dead air.
- **Buffer cadence** — the deliberate pause pattern between spoken lines, tuned so nothing feels rushed or robotic.
- **Clean release** — letting go of a robot's behavior control properly, so it doesn't get stuck thinking it still owns the mic.
- **Almost Doc Approved** — the project's own in-house "good enough to ship, not perfect yet" stamp.

### Parser and speech vocabulary

- **Action/Speech Split** — animation tags and spoken words get parsed apart before either one runs. "Animation is not text. Animation is an action."
- **Clean speech** — what's left of a line once animation tags and stage directions are stripped out for the mouth to actually say.
- **Robot-safe packet** — a chunk of text or command shaped so a robot can actually execute it without choking on it.

### Lanes and plateaus

- **Lane** — a first-class GOPOD noun: a distinct track of work (robot lane, audio lane, website lane) worked on its own.
- **Plateau** — a safe, proven stopping point to build the next thing from — not a dead end, a place to stand.
- **8011 cockpit** — the live laptop dashboard that shows a session's real-time state.

### Scene-mode language

- **HDB** — Home Departure Beacon, the "getting ready to leave" scene.
- **POTS** — Person On The Street, a scene built for one passerby.
- **PAAT** — People At A Table, a scene built for a group already seated.
- **CAWG** — CRUSHN8R Alone With Goverlord, the operator's own one-on-one working scene.
- **GPYS** — GOPOD Yourself, shorthand for the wake phrase itself.

### KP language

- **KP0** — the numpad key that exits or stops a session.
- **KP1 / KP2** — the numpad keys that route straight to Doc or Pip.
- **KP9** — the numpad key that routes to CHALK.

### Magic and doctrine

- **GOPOD magic** — the intangible "it just works" feeling a session gives off — worth protecting, not engineered away.
- **Living edge** — the rough, alive quality that makes GOPOD feel real instead of over-polished. "Do not sand off GOPOD's living edge. Shape it. Aim it. Let it breathe."

## Why the names are funny

A strange name is easier to remember than a plain one — "GOPOD Yourself" sticks in a way a plain description never would. A name someone remembers is a name they repeat to a friend. A name people repeat enough eventually gets typed into a search bar. Because nobody else made up "Brobots" or "GOPOD Yourself" or "Doc Squawkadoodle," typing it only leads back here — there's no crowd of other results to get lost in. The jokes aren't decoration sitting on top of the project. They're the reason someone who saw it once can find it again a month later.

## Goverlord, Gomads, and Gominions — where the working model came from

This is the operator's own canon wording, quoted verbatim from the live Wire-Pod knowledge-graph prompt and the Brobot persona prompt:

> Goverlord is the GOPOD brain and session orchestrator.
> Gomads are Goverlord's managers that go mad from their heavy workloads. Lol.
> Gomads hand off work to their Gominions.
> Gominions do the work.

This is the operator's working model for agents, sub-agents, and skills — the wordplay is the mental model, not decoration. "Gomad" is GO + MAD: a manager gone mad from workload. That's the recorded name origin.

Two places this maps to something real on disk:

- **`goverlord/runtime/data_gomad/`** — a surviving working example of the gomad layer. Git-tracked, live: it holds facts (endpoints, filesystem paths, audio constants, schema) that GOPOD's own code reads instead of hardcoding, called from `gopod_demo_8011.py`, `gopod_ptt_chat_writer_013.py`, and its own `config/loader.py`.
- **Gominions, traced forward:** the current live PTT writer, `goverlord/runtime/gopod_layer/web_display/gopod_demo_8011/gopod_ptt_chat_writer_013.py` (git-tracked), carries comments throughout citing `ptt_gominion1.py` as its source of ported logic — but that file itself is not present anywhere on disk today, and isn't git-tracked; it's a cited lineage, not a file that can be opened. What is confirmed: this same writer file was the direct, named source for `goverlord/runtime/songs/zzz_archives/102_brobots_cross_persona/story.md` (git-tracked, archived 2026-08-12 — the live `103_gopod_is_that_you` PTT+LLM test made this scripted reel redundant; renamed 2026-07-31 from `103_gopod_is_that_you`, which collided with the writer's own live `is-that-you` alias name) — that song's own header states it was "Derived 2026-07-25 from `goverlord/runtime/gopod_layer/web_display/gopod_demo_8011/gopod_ptt_chat_writer_013.py`," per the operator's own scope instruction. The chain from the "Gominion" name to today's song-video lane runs through that writer file — the earliest named link in the chain is a citation, not a file that still exists.
